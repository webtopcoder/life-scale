# Add payment methods to the default website footer

## Plan

1. Add the five supplied payment logos to the project assets and use those exact files.
2. Add one compact payment-method row to the shared `MarketingFooter`, ordered: Visa, Mastercard, Apple Pay, Google Pay, PayPal.
3. Place the row above the copyright area, size the logos consistently while preserving their proportions, and allow clean wrapping on narrow screens.
4. Keep the logos informational rather than clickable, with accessible names for screen readers.
5. Verify the shared footer on the homepage, a legal page, and mobile sizing; confirm no other footer content or layout changes.

## Scope

This updates every page that renders the standard Life Scale marketing footer, including pages using the shared marketing layout and standalone legal pages. Specialized in-app or report footers remain unchanged.
